# shiryo-sakusei

資料作成プロジェクト。Google スライド / Canva で資料を作成し、依頼内容・素材・成果物へのリンクをここで管理します。

## フォルダ構成

| フォルダ | 内容 |
|---|---|
| `briefs/` | 資料ごとの依頼内容（目的・対象者・構成案）。1資料1ファイル |
| `sources/` | 元データ・参考資料・原稿 |
| `outputs/` | 完成資料へのリンク一覧、書き出したPDFなど |

## 使い方

1. `briefs/_template.md` をコピーして依頼内容を書く
2. Claude に「`briefs/◯◯.md` の資料を作って」と依頼する
3. 完成した資料の URL が `outputs/` に記録される
